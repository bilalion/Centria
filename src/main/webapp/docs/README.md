# Centria Platform

A modern SaaS platform for managing educational support centers.

Developed by **CHENTOUF Bilal**.

---

# Project Vision

Centria is designed to provide a complete management platform for educational support centers.

The platform aims to simplify daily operations, automate administrative tasks, and provide an intuitive experience for administrators, teachers, parents, and students.

---

# Project Structure

The project is divided into multiple phases.

## Phase 1 — Centria Platform

Platform administration.

Features:

- Dashboard
- Centres Management
- Payments Management
- Subscription Management
- Settings
- Multi-language Support
- Authentication
- Security

Status:

**In Development**

---

## Phase 2 — Centria Manager

Management application used by support center owners.

Planned features:

- Student Management
- Teacher Management
- Class Scheduling
- Attendance
- Revenues
- Expenses
- Teacher Payments
- Reports

Status:

Planned

---

## Phase 3 — Centria Teacher

Teacher portal.

Planned features:

- Teaching Schedule
- Student Lists
- Attendance
- Salary Information
- Personal Dashboard

Status:

Planned

---

## Phase 4 — Centria Parent

Parent portal.

Planned features:

- Student Attendance
- Payment Status
- Schedule
- Notifications
- Academic Follow-up

Status:

Planned
